Как работает

Вопросы

FAQ

Что нужно для работы?

Windows 10/11, микрофон и игра Россия Онлайн (Majestic). Интернет нужен только для проверки подписки — распознавание речи работает офлайн.

Можно на двух компьютерах?

Один ключ привязывается к одному ПК. Для второго устройства нужен отдельный ключ. Перенос на новый ПК — по запросу.

Это безопасно?

Приложение не вмешивается в игру и не даёт преимуществ — это справочник законов, который быстро показывает нужную статью по голосу.

Что при окончании подписки?

Доступ закроется до продления. Продлить — снова оплатить в боте и ввести новый ключ.

Видно ли подсказки на записи?

При записи «в игре» подсказки в клип не попадают. Для записи рабочего стола есть отдельная настройка.
