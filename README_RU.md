# VERDICTA — прямое скачивание установщика

В этом архиве — подготовленный патч для статического сайта на Netlify. Кнопка «Скачать приложение» в `index.html` ведёт на `/.netlify/functions/download`. Функция запрашивает свежую ссылку скачивания у публичного API Яндекс Диска и отвечает HTTP-редиректом на установщик.

## Файлы
- `index.html` — исходная страница с заменённой ссылкой скачивания.
- `styles.css` — исходные стили без изменений.
- `netlify/functions/download.mjs` — обработчик редиректа.
- `netlify.toml` — конфигурация публикации и каталога функций Netlify.

## Как внедрить
1. Сначала сделайте резервную копию текущего сайта.
2. Сравните `index.html` и `styles.css` из архива с актуальными файлами вашего проекта. Если на сайте уже есть более свежие изменения, перенесите только замену ссылки и добавьте функцию, не перезаписывая весь файл.
3. Скопируйте каталог `netlify/functions` и конфигурацию функции в корень проекта. Проверьте, не существует ли уже `netlify.toml`: если есть, объедините настройки, не затирая текущие параметры сборки.
4. Разместите изменения через Git/Netlify CLI или другой способ деплоя, который поддерживает Netlify Functions. Простая публикация одних HTML-файлов не разворачивает серверную функцию.
5. После деплоя откройте `https://ВАШ-ДОМЕН/.netlify/functions/download`. При успехе браузер должен перейти к скачиванию EXE. Затем проверьте кнопку на сайте.

## Важно
- Функция ожидает, что файл в корне публичной папки Яндекс Диска называется точно `RO-Pomoshnik-Setup.exe`. Если название или расположение другое, поправьте `installerPath` в `download.mjs`.
- Ссылка Яндекс Диска должна оставаться публичной.
- Я не могу опубликовать изменения на вашем Netlify из этого архива и не утверждаю, что реальный редирект уже проверен на вашем сайте. Проверьте после деплоя.
- Если API не находит файл по указанному пути, проверьте точное имя и расположение файла в публичной папке.
